# 好好意语 A1-A2 Percorso

移动端优先的 A1-A2 毕业测试网页系统。

## 功能

- 微信浏览器可打开
- 从 100 道题库中按规则随机抽取 50 题
- 选项顺序保持题库原顺序
- 自动评分
- 自动生成学习诊断报告
- 判断 A2 达标与 B1 预备水平
